# Marketing drafts

Copy-paste material for promoting the project. Everything here needs to be posted from a personal account.

| File | Where to post |
|---|---|
| `awesome-list-pr.md` | PRs to awesome-claude-code / awesome-claude-skills style lists |
| `show-hn.md` | news.ycombinator.com → submit |
| `reddit.md` | r/ClaudeAI, r/philosophy, r/artificial |
| `blog-post-en.md` | dev.to, Medium, Hacker Noon |
| `blog-post-zh.md` | 少数派、知乎、即刻、V2EX |

Order that works: awesome-list PRs first (they take days to merge), then Show HN on a weekday morning US time, then Reddit the next day, then the blog post linking to the HN thread.

After posting, check `stats/traffic.json` the following week to see which referrer sent the most visitors.
